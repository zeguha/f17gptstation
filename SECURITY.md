# Политика безопасности

## Секреты

- Не коммитьте `.env`, файлы из `.secrets/`, `.state/`, токены OAuth, API-ключи и локальные IP-адреса устройств.
- Для локального запуска используйте `.env`, созданный из `.env.example`.
- Для GitHub Actions используйте GitHub Secrets, а не значения в YAML.
- Если секрет попал в коммит, считайте его скомпрометированным: отзовите/перевыпустите ключ и очистите историю репозитория перед публикацией.

## Сообщение об уязвимостях

Открывайте приватное security advisory в GitHub или свяжитесь с владельцем репозитория до публичного раскрытия.
